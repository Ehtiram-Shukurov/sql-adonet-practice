# SQL & ADO.NET Practice

Database and ADO.NET exercises from the Software Development program at 
Code Academy (Baku, Sept 2022 – Jan 2023).

## Contents

- **sql-practice** — A collection of standalone SQL scripts covering joins, 
  stored procedures, roles, and subcategory queries.
- **adonet-practice** — Console app practicing raw SQL queries via ADO.NET.
- **adonet-practice2-consoleapp** — A second ADO.NET console exercise.

> Note: these are archived coursework projects, not maintained or deployed.
